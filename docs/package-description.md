# PF2e Artisan's Workshop

One place to run crafting for the whole party in the PF2e system: a shared request queue, pooled
funding with a ledger of who paid for what, crafting days and progress for every item, daily
preparations, and downtime Earn Income paid straight to the earner.

Everything is read from the characters and the system's own crafting rules. Nothing waits on a GM:
players can request, fund and craft with no GM connected. It works alongside pf2e-dailies, PF2e
Toolbelt, PF2e Workbench and Item Piles.

This module is in development and has not been released.
